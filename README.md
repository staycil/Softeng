# Deskripsi Project
Program ini menerima input sejumlah bilangan bulat, mengurutkannya, dan mencetak nilai median dari sekelompok bilangan.

# Cara Menjalankan
Compile file:
g++ M.cpp -o sort
# Jalankan program:
./sort
Masukkan jumlah kelompok a lalu 3*a angka.

# Contoh input:
2
9 5 1 4 7 6

# Output:
5
